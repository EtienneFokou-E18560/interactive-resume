# efokou-lab sample

Read-only GitOps demo materials for the Engineering Lab sandbox.

Explore with allowlisted commands only (`help` inside the lab).

## Layout

- `k8s/` — example Deployment and Service manifests
- `terraform/` — example local provider module (no cloud credentials)
- `docs/` — architecture notes for the demo

This repository is copied into a disposable workspace per session. Nothing here talks to production clusters or cloud accounts.
